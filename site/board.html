What the factory opened, and what maintainers did with it

An automated pipeline opens pull requests in other people's open-source projects. This page counts all of them, including the ones that were closed, left unanswered or reworked.

Not measured

  • How long maintainers take to answer, approve or merge. That time is theirs, so it is not a factory number.
  • Cost per pull request, in agent time or tokens. Worker sessions are not attributed to items yet.
  • How often a person had to step in during a scheduled session. Sessions carry no intervention record yet.
  • Reverts and regressions after a merge. Follow-up stops when a pull request merges.

Board 08Method

How to check these numbers

  • The list of pull requests comes from the factory's ledger and is reconciled with GitHub's own search. The comparison has not run for this snapshot.
  • Closed, withdrawn and unanswered pull requests stay in the merge-rate denominator. A merge counts only when GitHub shows the pull request as merged. Merged without rework is a share of the merges.
  • A change after opening is read from the pull request's commits, reviews and force-push events. Ordinary push times are not published by GitHub, so commit dates stand in for them.
  • Rates are shown only for 20 pull requests or more. Intervals are 95% Wilson intervals and ignore clustering by project.
